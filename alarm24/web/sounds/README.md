# Alarmtöne

Lege hier die Audiodatei für den Alarmton ab, z. B. `alarm.mp3` (siehe `Config.AlarmSound.file` in `config.lua`).

Aus Lizenzgründen wird keine Audiodatei mitgeliefert. Die App funktioniert auch ohne Datei
einwandfrei weiter (Wiedergabefehler werden im Frontend abgefangen), es fehlt dann nur der Ton.

Empfohlenes Format: MP3 oder OGG, kurz (2–4 Sekunden), gut hörbar/durchdringend.
